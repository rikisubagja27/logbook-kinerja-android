LOGBOOK KINERJA — PROYEK ANDROID (CAPACITOR)

PENTING
- Proyek ini membungkus index.html yang diberikan pengguna; tampilan aplikasi dipertahankan.
- URL Supabase lama tertanam dalam index.html dan tidak diubah.
- Ini adalah proyek sumber Android, BUKAN APK yang sudah dikompilasi.
- Google Drive tidak dinyatakan aktif oleh paket ini; file deploy sumber menyebut integrasi Drive perlu backend/OAuth terpisah.
- Jangan menghapus project Supabase, tabel, bucket, atau situs Netlify lama.

CARA MEMBANGUN APK
Diperlukan komputer/laptop dengan Android Studio, Android SDK, Java JDK, dan koneksi internet.

1. Ekstrak ZIP ini di komputer.
2. Instal Node.js LTS dan Android Studio.
3. Buka terminal pada folder hasil ekstrak, jalankan:
   npm install
   npx cap add android
   npx cap sync android
   npx cap open android
4. Android Studio akan membuka proyek Android. Tunggu Gradle selesai mengunduh dependensi.
5. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Setelah selesai, Android Studio menampilkan tautan lokasi APK. Untuk APK debug biasanya di android/app/build/outputs/apk/debug/app-debug.apk.
7. Pasang APK di Android dan uji login, simpan data, unggah foto, dan laporan sebelum digunakan sehari-hari.

CATATAN
- Aplikasi memerlukan internet untuk Supabase.
- Pastikan kamera/foto, login, unduh Word/PDF, dan alur laporan diuji di perangkat Android.
- Bila login Supabase menggunakan redirect URL tertentu, mungkin diperlukan penyesuaian callback Android setelah diuji.
- Jangan membagikan kunci service_role. Jangan masukkan rahasia backend ke aplikasi Android.
